# Thocow

Um jogo estilo Flappy Bird — mas com uma vaquinha voando entre cercas de madeira.

## Como jogar

- **Clique / toque** na tela ou aperte **Espaço** para a vaquinha bater as asas
- Passe entre as cercas para marcar pontos
- Não bata nas cercas nem no chão

## Rodar localmente

Abra o arquivo `index.html` no navegador. É só isso — sem build, sem dependências.

```bash
# ou rode um servidor estático qualquer, por exemplo:
python -m http.server 8000
# depois acesse http://localhost:8000
```

## Tecnologia

HTML5 Canvas puro, sem frameworks. Tudo num único arquivo `index.html`.

## Recorde

O recorde é salvo localmente no navegador via `localStorage`.
